#### 4. 取消功能
- [ ] 等待回覆時按鈕顯示「取消」
- [ ] 點擊取消按鈕可停止處理

#### 5. 記帳功能

- [ ] 切換會話時載入正確的歷史訊息

## 快速測試步驟

### 1. 啟動應用

```bash
# 終端 1：啟動後端
cd backend
npm run dev

# 終端 2：啟動前端
cd frontend
npm run dev
```

### 2. 基本功能測試

1. 打開瀏覽器訪問前端地址
2. 確認顯示「已連線」
3. 發送測試訊息："你好"
4. 確認收到 AI 回覆
5. 點擊「新建」創建新會話
6. 發送記帳相關訊息：「我今天花了 50 元買咖啡」
7. 確認出現記帳確認卡片
8. 測試確認和取消按鈕

### 3. 邊界情況測試

1. 測試空白訊息（不應發送）
2. 測試長訊息（換行顯示）
3. 測試快速切換會話
4. 測試收起側邊欄後的操作
5. 測試網路斷線情況
